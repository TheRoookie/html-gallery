LCP Hero Image Has loading="lazy"

Check #160 • Image Analysis
+

The Largest Contentful Paint element on this page (.hero-bg img) has a loading="lazy" attribute. Lazy loading intentionally defers resource fetching until the element is near the viewport — for the LCP element, it is always in the viewport immediately, making lazy loading counterproductive and directly worsening Core Web Vitals.

How to Fix

Remove loading="lazy" from the hero image entirely. For the LCP image specifically, also add a preload link in the head and set fetchpriority.

<!-- Before (broken) -->
<img src="/images/hero-banner.jpg" loading="lazy" class="hero-bg">

<!-- After (correct) -->
<img src="/images/hero-banner.webp" fetchpriority="high" class="hero-bg"
     width="1440" height="720" alt="ACME Digital — Growth Marketing Agency">

Organization Schema Missing

Check #57 • Structured Data
+

The homepage has no Organization schema in JSON-LD or microdata format. The homepage is the primary page for brand entity recognition. Without it, Google's Knowledge Graph has no structured starting point for understanding the brand entity.

How to Fix

Add the following JSON-LD block to the <head> of the homepage. Serve it server-side (not JS-injected).

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "ACME Digital",
  "url": "https://acme-digital.com"
}
</script>
